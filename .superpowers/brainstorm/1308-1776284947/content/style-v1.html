Visual Style

Choose the aesthetic direction for the UI

A

Current (Dark Slate + Emerald)

Keep the existing dark theme: slate backgrounds, emerald/cyan accents, glassmorphism cards, rounded corners.

B

Minimal Dark

Clean, minimal chrome. Near-black backgrounds, subtle borders, monochrome accents. Think VS Code meets Linear.

C

Gradient Bold

Vibrant gradient backgrounds, bold color blocking, glowing accents. More expressive, less subtle.

D

Terminal Aesthetic

Inspired by terminal UIs — monospace fonts, CRT-style glow effects, phosphor green or amber accents, scan lines optional.
