Design — Section 3: Track C — Session Management

Full session lifecycle, export, search

Backend Endpoints

  • GET /api/sessions/list — existing, enhanced to include: date grouping metadata, archive status
  • POST /api/sessions/create — creates new Hermes session, returns session ID + title
  • PATCH /api/sessions/:id — rename session, update color/tag, archive/unarchive
  • DELETE /api/sessions/:id — soft-delete (archive) or hard-delete
  • GET /api/sessions/:id/export — returns full transcript as Markdown or JSON
  • GET /api/sessions/search?q= — search session titles and content via Hermes

Session Picker (Sidebar)

  • Current behavior: simple dropdown of session options — replaced with a proper session list panel
  • Session list panel: collapsible section in the sidebar showing all sessions grouped by date (Today, Yesterday, Earlier, Archived)
  • Per-session actions: hover reveals icon buttons — rename (pencil), duplicate, archive, delete
  • New session button: prominent "+" button at top, creates and immediately switches to new session
  • Session color/tag: optional color dot and short tag label for visual grouping

Session Search

  • Search bar at top of session list — queries Hermes session index
  • Results show matching sessions with highlighted content snippets
  • Filters: All | Archived | By tag/color

Export

  • Per-session export button: downloads .md or .json file
  • Format: Markdown includes metadata header (session ID, date, model), then role-labeled message blocks
  • JSON format includes full structured data for re-import
